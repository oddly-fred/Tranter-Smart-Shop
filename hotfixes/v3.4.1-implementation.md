# v3.4.1 visibility fix

This hotfix addresses two homepage problems visible in the deployed v3.4.0 screenshot:

1. Green glass section pills used near-white text on light sections, making labels difficult to read.
2. The partner area showed text placeholders rather than the supplied OEM/partner logo artwork, while its dark background was not reliably enforced.

## Applied in the packaged plugin

- Context-aware pill colours: dark green text on light sections and white text on dark sections.
- Stronger glass borders, contrast and text shadows for dark-section pills.
- Explicit dark navy/green background colour and image for the partner section.
- A real partner-logo image panel extracted from the supplied artwork.
- SEO-friendly image alt text and a visually hidden semantic list of OEM/partner names and technology categories.
- Mobile horizontal scrolling for the wide logo panel.
- Plugin version advanced to 3.4.1.

Installable package: `tranter-smart-shop-v3.4.1-visibility-fix.zip` generated from the updated plugin source.
